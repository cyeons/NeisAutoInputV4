프로그램 소개

NeisAutoInputV4는 학생별 평어와 행동특성을 준비하고, 준비한 내용을 NEIS 입력칸에 순서대로 자동 입력하는 프로그램입니다.

문장을 직접 작성할 수도 있고, Gemini 또는 OpenAI를 이용해 교과 평어와 행동특성 문장을 만들 수도 있습니다.

왼쪽 메뉴

  1. 자동 입력 — 학생 이름과 내용을 관리하고 NEIS 자동 입력을 실행합니다.
  2. AI 평어 — 성취기준을 선택하여 교과 평어를 생성합니다.
  3. 행동발달 — 학생별 특성을 선택하여 행동특성 및 종합의견을 생성합니다.
  4. 환경 설정 — AI 서비스, API 키와 창 동작을 관리합니다.

  • 키는 복사한 뒤 프로그램에 바로 등록합니다.
  • 키가 노출되었다면 발급 사이트에서 삭제하고 새 키를 만듭니다.
