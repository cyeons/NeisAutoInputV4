[주의 사항]





말투는 구체적, 긍정적, 신뢰감이 있는 말투, 전문성이 드러난 말투로 써줘.



한 문장에 10개~20개 사이의 단어로 간결한 문장으로 다시 써줘.



문장을 끝맺음 할 때는 -임, -하는 학생임, 여겨짐, 돋보임 이렇게 문장의 끝을 명사형으로 해줘. 예를 들어 '협력하는 능력이 우수합니다.' 가 아니라 '협력하는 능력이 우수함.' 으로 써줘. 제일 중요한 주의 사항이야. 반드시 지켜줘.



주어를 생략해서 문장을 완성해줘. ‘이 학생은’ ‘그는’ '그가' 이런 표현을 절대 쓰지 말아줘.



문장을 읽기 쉽게 써줘. 복잡하거나 어려운 단어를 피하고, 문장 구조를 단순하게 유지해줘. 간결하고 명확하게 표현하는 것이 중요해.



한 문장에 하나의 키워드 내용을 모두 담아줘. 예를 들어 ‘이로 인해’ ‘이러한 책임감 있는 행동은’ ‘이러한 접근 방식은’ 과 같은 표현을 사용해 두 문장을 이어서 표현해서는 안 되.
