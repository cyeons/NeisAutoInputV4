# NeisAutoInput V4 현행 개발 계획

## 1. 문서 목적

이 문서는 현재 구현된 NeisAutoInput V4의 구조와 동작을 기준으로 유지보수 방향을 정리한다.
초기 제안서의 미구현 목표를 나열하지 않고 실제 프로그램의 동작을 현행 사양으로 삼는다.

## 2. 제품 목표

- 기존 NEIS 자동 입력 흐름을 유지하면서 PySide6 기반 데스크톱 UI를 제공한다.
- 교과 평어와 행동특성 및 종합의견 생성을 Gemini와 OpenAI로 지원한다.
- 학생 명단을 자동 입력 화면과 행동발달 화면에서 공유한다.
- API 키는 평문 파일이 아닌 운영체제 자격 증명 저장소에 보관한다.
- UI·저장소·AI 공급자·자동 입력 로직을 모듈로 분리하여 유지보수와 테스트가 가능하게 한다.

## 3. 기술 구성

- UI: `PySide6`
- 자동 입력: `pyautogui`, `pyperclip`, `keyboard`
- Gemini SDK: `google-genai`
- OpenAI SDK: `openai`
- 보안 저장소: `keyring`
- 배포: `PyInstaller`

## 4. 화면 구성

프로그램은 사이드바 기반의 네 화면으로 구성한다.

### 4.1 자동 입력

- 학생 이름과 입력 내용을 2열 표로 편집한다.
- `data.csv`에 이름과 내용을 저장하고 불러온다.
- `student.csv`에 학생 이름을 별도로 저장한다.
- 이동할 Tab 횟수, 입력 간격, 앞 공백, 마우스 긴급 중지를 설정한다.
- 일반 시작은 5초 카운트다운 후 실행한다.
- 선택 기능 키를 눌러 즉시 시작하는 모드를 제공한다.
- 실행 중 진행률과 현재 학생 행을 표시한다.
- `Esc` 또는 마우스 화면 모서리 이동으로 중지할 수 있다.

### 4.2 AI 평어

- 학년군·교과·영역별 성취기준을 검색하고 선택한다.
- Gemini와 OpenAI 중 API 키가 등록된 서비스를 선택한다.
- 지원 모델 목록에서 모델을 선택한다.
- 학생 수와 학생별 문장 수를 지정하여 교과 평어를 생성한다.
- 최근 결과를 프롬프트에 포함하여 표현 반복을 줄인다.
- 결과 줄 수가 요청 학생 수와 다르면 한 번 보정 요청한다.
- 생성 결과를 복사하거나 NEIS 입력 표에 순서대로 넣는다.

### 4.3 행동발달

- 자동 입력 화면과 동일한 학생 명단을 UUID 기준으로 공유한다.
- 교과 및 인성·행동·태도 특성을 학생별로 선택한다.
- 특성 단계는 강점·일반·성장 필요로 구분한다.
- 현재 학생 또는 특성이 선택된 전체 학생을 생성한다.
- 생성 결과를 편집하고 글자 수·UTF-8 byte 수·문장 수를 확인한다.
- 초안이 있는 학생의 결과를 UUID 기준으로 NEIS 표에 적용한다.
- 자세한 현행 사양은 `docs/plan_hb.md`를 따른다.

### 4.4 환경 설정

- 창 항상 위 표시를 설정한다.
- 교과 평어와 행동발달의 공급자·모델 설정을 각각 유지한다.
- Gemini와 OpenAI API 키를 등록하거나 삭제한다.

## 5. 데이터와 저장

- `config.json`: 창, 매크로, 공급자, 모델, 행동발달 기본 문장 수 설정
- `data.csv`: 학생 이름과 NEIS 입력 내용
- `student.csv`: 재사용할 학생 이름
- `hb_work.json`: 학생 UUID, 행동 특성, 초안과 생성 상태
- `hb_custom_traits.json`: 사용자 추가 행동 특성
- `resources/achievement_standards.json`: 교과 평어 성취기준
- `resources/behavior_traits.json`: 행동발달 기본 특성 카탈로그
- API 키: `keyring`을 통한 운영체제 자격 증명 저장소

학생 CSV와 행동발달 JSON 저장은 임시 파일을 작성한 뒤 교체하는 방식으로 처리한다.
개발 환경에서는 프로젝트 폴더를 사용하고 PyInstaller 실행 파일에서는 사용자 AppData 폴더를 런타임 저장 위치로 사용한다.

## 6. 코드 구조

- `main.py`: 프로그램 진입점
- `neis_v4/app.py`: QApplication 생성 및 실행
- `neis_v4/ui/main_window.py`: 네 화면 등록과 화면 간 연결
- `neis_v4/ui/neis_tab.py`: 자동 입력 표와 매크로 설정
- `neis_v4/ui/ai_tab.py`: 교과 평어 생성
- `neis_v4/ui/behavior_tab.py`: 행동발달 특성 선택·생성·적용
- `neis_v4/ui/settings_tab.py`: 전역 설정과 API 키 관리
- `neis_v4/models.py`: 설정·학생·AI 요청·행동발달 데이터 모델
- `neis_v4/roster.py`: 화면 간 공유 학생 명단
- `neis_v4/storage.py`: 설정·CSV·JSON·리소스 저장 및 로드
- `neis_v4/secrets.py`: API 키 보안 저장
- `neis_v4/ai/`: Gemini·OpenAI 공급자와 프롬프트·응답 처리
- `neis_v4/automation/runner.py`: QThread 기반 자동 입력 실행

## 7. AI 처리 원칙

- UI와 공급자 호출을 분리하고 생성 작업은 QThread에서 실행한다.
- 교과 평어는 공용 `GenerationRequest`와 `GenerationResult`를 사용한다.
- 행동발달은 UUID만 외부 요청에 포함하며 학생 이름은 전송하지 않는다.
- 행동발달 요청은 최대 10명 단위로 나눈다.
- 일부 행동발달 묶음이 실패해도 이미 성공한 묶음은 유지한다.
- 일시적인 공급자 오류는 지수형 대기 후 최대 두 번 재시도한다.
- 공급자가 지원하면 JSON Schema 구조화 출력을 사용하고 지원하지 않으면 JSON 출력으로 대체한다.

## 8. 패키징

- `NeisAutoInputV4.spec`에 리소스, 아이콘, 글꼴과 필요한 숨은 import를 등록한다.
- 사용하지 않는 PySide6 선택 구성요소와 이미지 코덱은 배포 파일에서 제외한다.
- 빌드 명령은 다음과 같다.

```powershell
pyinstaller NeisAutoInputV4.spec
```

## 9. 현재 자동 테스트

`tests/`는 다음 범위를 검증한다.

- 성취기준 카탈로그의 교과·코드 구성
- 행동 특성 카탈로그와 사용자 특성 저장
- 학생 UUID 기반 행동발달 결과 매핑
- 행동발달 작업 JSON 저장과 이전 스키마 마이그레이션
- 행동발달 UI 생성·특성 선택·문장 수 설정·결과 적용
- 묶음 생성의 부분 성공 보존과 일시 오류 재시도
- 자동 입력 시작키와 5초 기본 카운트다운
- 공급자별 모델 설정과 API 키 등록 상태

실행 명령:

```powershell
python -m unittest discover -s tests -v
```

## 10. 배포 전 확인

- `python main.py` 실행과 네 화면 전환
- `data.csv` 및 `student.csv` 저장·불러오기
- API 키 등록·삭제와 평문 키 파일 미생성 확인
- Gemini와 OpenAI의 소규모 실제 생성
- 생성 결과의 NEIS 표 적용
- 메모장에서 자동 입력·중지·기능 키 시작 확인
- PyInstaller 빌드 후 리소스와 사용자 데이터 경로 확인
